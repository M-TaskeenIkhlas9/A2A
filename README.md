# AURELION - Premium Clothing Brand Website

A modern, elegant, and luxury clothing brand e-commerce frontend built with Next.js, Tailwind CSS, and Framer Motion.

- [Scope Summary](./docs/SCOPE.md) - Project scope and deliverables
- [Tech Stack](./docs/TECH_STACK.md) - Technology decisions and rationale
- [Out of Scope](./docs/OUT_OF_SCOPE.md) - Excluded features and future considerations

## Quick Start

```bash
npm install
npm run dev
```

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript

## Design System

| Token | Value | Usage |
|-------|-------|-------|
| Primary | `#000000` | Text, backgrounds |
| Secondary | `#FFFFFF` | Backgrounds, text on dark |
| Accent | `#C9A96E` | CTAs, highlights |
| Background | `#F5F5F5` | Page backgrounds |

**Typography**:
- Headings: Playfair Display (Serif)
- Body: Inter (Sans-serif)
