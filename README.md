# AURELION - Premium Clothing Brand Website

A modern, elegant, and luxury clothing brand e-commerce frontend built with Next.js, Tailwind CSS, and Framer Motion.

## Project Status

**Current Phase:** Scope and Architecture Lock ✅

## Quick Overview

### Pages (7)
1. Home / Landing Page
2. Shop Page
3. Product Detail Page
4. Cart Page
5. Checkout Page
6. About Page
7. Contact Page

### Tech Stack
- **Framework:** Next.js 14 with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **Icons:** Lucide React

### Design System
- **Colors:** Black (#000000), White (#FFFFFF), Gold Accent (#C9A96E)
- **Typography:** Playfair Display (headings), Inter (body)
- **Breakpoints:** Mobile (<640px), Tablet (640-1024px), Desktop (>1024px)
