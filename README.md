# AURELION - Premium Clothing Brand Website

A modern, elegant, and luxury clothing brand e-commerce frontend built with Next.js, Tailwind CSS, and Framer Motion.

## Project Documentation

| Document | Description |
|----------|-------------|
| [Scope Summary](./docs/SCOPE_SUMMARY.md) | Complete feature list, pages, and requirements |
| [Tech Stack](./docs/TECH_STACK.md) | Technology decisions and project structure |
| [Out of Scope](./docs/OUT_OF_SCOPE.md) | Explicitly excluded features and future phases |

## Quick Overview

**Tech Stack:** Next.js 14 + TypeScript + Tailwind CSS + Framer Motion

**Pages:** Home, Shop, Product Detail, Cart, Checkout, About, Contact

**Design:** Minimalist luxury aesthetic with black/white/gold color scheme

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
