# AURELION – Premium Clothing Brand Website

A modern, elegant, and luxury clothing brand e-commerce frontend inspired by high-end fashion brands.

## Project Status

**Current Milestone:** Scope and Architecture Lock ✅

## Quick Overview

### Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **State:** React Context API

### Design System
| Token | Value |
|-------|-------|
| Primary | #000000 |
| Secondary | #FFFFFF |
| Accent | #C9A96E |
| Background | #F5F5F5 |
| Heading Font | Playfair Display |
| Body Font | Inter |

### Pages
1. Home (Landing Page)
2. Shop
3. Product Detail
4. Cart
5. Checkout
6. About
7. Contact

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
